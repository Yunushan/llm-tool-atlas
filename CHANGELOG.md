# Changelog

All notable changes to this project will be documented here.

## [Unreleased]

### Changed

- Hardened full-catalog validation, JSON schemas, source URL checks, Markdown
  rendering, local-link checking, and release metadata validation.
- Added deterministic release archives, checksums, cross-platform verification,
  pinned CI actions, freshness/link-audit reporting, Dependabot, CODEOWNERS,
  and recovery guidance.
- Corrected sourced pricing, licensing, platform, lifecycle, and model-capability
  records and split model inputs, outputs, and capabilities into controlled fields.
- Restricted release attestations and uploads to the four expected assets so
  stale files cannot leak into a published release.

## [0.1.0] - 2026-08-04

### Added

- Initial catalog of AI coding tools, model families, gateways, and local
  runtimes.
- Source-linked pricing and capability fields with verification dates.
- Scenario-based chooser, comparison guides, security checklist, and glossary.
- Dependency-free validation, deterministic table generation, and CI checks.
