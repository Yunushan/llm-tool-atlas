# Support

LLM Tool Atlas is maintained as a source-linked public catalog, not as a hosted
AI service.

- For a wrong price, capability, license, lifecycle, or source link, open an
  issue with the affected record ID, the official source, and the date checked.
- For contribution questions, read [Contributing](CONTRIBUTING.md).
- For a security issue in this repository, follow [Security](SECURITY.md) and
  do not include exploit details in a public issue.
- For a listed product's outage, billing dispute, privacy request, or security
  disclosure, contact that product's vendor directly.

There is no guaranteed response time for ordinary catalog corrections. Pull
requests with a direct official source and a reproducible verification command
are easiest to review.
